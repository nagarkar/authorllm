# Teaching notes

- The learner already knows how to start an AuthorLM session and use chat.
- Prefer short lessons that operate on live SMSTTD work and produce an immediate editorial decision.
- Teach distinctions between state machines before teaching command breadth.
- Do not mutate SMSTTD during an exercise until the learner gives the substantive verdict.
- Prefer AuthorLM's public CLI surface over custom Python or direct database reads, even for inspection. If the CLI lacks a needed read path, name the gap instead of bypassing it casually.
